# Support

## Getting Help

If you encounter a bug or unexpected behaviour, please [open a GitHub Issue](https://github.com/gjackirl/claude-software-factory-demo/issues/new) in this repository. When filing an issue, include steps to reproduce the problem, the version of the project you are using, and any relevant logs or error messages.

For general questions about usage or the project's direction, feel free to open a GitHub Discussion or comment on an existing issue.

## No Dedicated Support Channel

There is currently no dedicated support channel (e.g. Slack, Discord, or email list) for this project. All support requests should be handled through GitHub Issues so that the conversation is visible to the whole community and answers can benefit everyone.

We appreciate your patience and contributions!
